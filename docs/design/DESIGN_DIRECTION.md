# BuzzKey design direction

The [BuzzKey UI concept](buzzkey-ui-concept-v1.png) is the current visual
reference for a later redesign. It depicts light and dark variants with an
orange ID. Buzz-inspired accent, prominent vehicle status, and native iPhone
controls. It is a direction, not a requirement to copy every screen or sample
number literally. Phase 1 does not implement UI changes.

The intended primary navigation is **Home, Analytics, Settings**. Trips and
Insights can live under Analytics. Vehicle controls can remain on Home unless
later usability testing supports a separate Controls tab. Home should make
vehicle status and its freshness clear, with access to lock, charge, climate,
and **Camp Mode**. A control's requested state must remain distinct from
confirmed vehicle state.

Support light and dark modes, use the orange accent for primary actions and
selected navigation, and retain native iOS interaction patterns, legible
contrast, accessibility labels, and explicit confirmation for sensitive
actions. The concept's Analytics cards and sample efficiency insights are
illustrative; future calculations must be based on actual available telemetry
and defensible analysis. A future Review/Demo Mode should present the app
without any path to live VW commands.
