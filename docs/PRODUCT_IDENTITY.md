# BuzzKey product identity

These are the authoritative identifiers for future native builds and App Store
Connect work. They are identifiers, not secrets. Phase 1 does not change the
current Expo or native application configuration.

| Field                 | Value                     |
| --------------------- | ------------------------- |
| App name              | BuzzKey                   |
| iOS bundle identifier | `com.ecardoso626.buzzkey` |
| App Store Connect SKU | `buzzkey-ios-001`         |
| Apple App ID          | `6818703335`              |

Use these exact values when the later local Xcode signing/archive phase is
authorized. Keep build numbers and the private API origin as separate release
configuration decisions.
